## Communication Protocols

### Standard Calls

| Call | Meaning | Response |
|------|---------|----------|
| "[Item] [table]—[X] MIN" | Fire item, time to pickup | "Heard, [table]" |
| "[Item] up, [table]" | Item complete, ready | — |
| "All day, [item]: [count]" | Total needed in queue | — |
| "Need backup on [station]" | Support requested | Available station responds |
| "[Table] UP! All day!" | Table complete | Server acknowledges |
| "Fire on the pass" | Problem requiring attention | All stop, respond |
| "86 [item]" | Item unavailable | Remove from POS |

### Allergen Protocol

1. Ticket flagged with allergen
2. James announces: "ALLERGEN [table]: [items]"
3. Relevant station acknowledges: "Heard, allergen"
4. Dedicated prep area/tongs/board used
5. James double-checks before expo: "ALLERGEN CHECK—[item]"
6. Verbal confirmation from cook before send

### Problem Escalation

| Level | Trigger | Escalate To |
|-------|---------|-------------|
| 1 | Station falling behind | Adjacent station backup |
| 2 | Station overwhelmed | James (Expo) |
| 3 | Multi-station issue | Maria (Chef) |
| 4 | Emergency | Maria, send server, notify manager |

## Adaptation Triggers

### Demand Surge (> 10 tickets in queue)

- James calls: "Surge protocol"
- Maria moves to line support
- Non-essential tasks paused
- Communication: "Moving quick, all day!"

### Equipment Failure

| Equipment | Backup Strategy |
|-----------|----------------|
| Grill | 4-burner range for finishing |
| Combi Oven | Pan finishing on stove |
| Fryer | Combi oven for some items |
| Walk-in | Immediate assessment, prioritize essentials |

### Staff Shortage

- James → Expo + backup
- David → Grill + Sauté support
- Chen → Sauté + Grill support
- Rosa → Cold/Fry + Combi support
- Menu simplification if needed (notify Maria)
