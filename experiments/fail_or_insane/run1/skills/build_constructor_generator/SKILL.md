# Build Constructor Generator

## Skill: Construct a meta-level generative apparatus for producing Workflow Generation System Constructors

## Purpose

This skill constructs a **Constructor Generator** — a meta-level apparatus that produces Workflow Generation System Constructors from specifications. The generator embodies the recursive capacity to generate generators, transforming abstract kitchen contexts into the conditions of possibility for workflow generation systems, which in turn generate daily workflow instances.

## Function

The Constructor Generator transforms five specification types into deployable constructor instances:

1. **Domain Specification** → Kitchen operational patterns, food safety constraints, equipment capabilities
2. **Architecture Specification** → Static design, dynamic design, learning design structure requirements
3. **Grammar Specification** → Production rules, constraint satisfaction logic, preference optimization
4. **Feedback Specification** → Capture interfaces, extraction mechanisms, integration protocols
5. **Configuration Parameters** → Kitchen context, scale, cuisine type, service style

## Principle

System building constructs living patterns maintained through feedback. The Constructor Generator must itself embody this principle: it produces constructors that learn, and it itself learns from the performance of constructors it produces. The feedback loop is not optional but constitutive of the generator's identity.

## Operation

The generator operates through template instantiation: pre-defined structures with slots for domain-specific content. Templates encode the invariant form ensuring consistency across generated constructors. The generator:

1. Validates incoming specifications
2. Selects appropriate templates from the template library
3. Binds specification content to template slots
4. Assembles instantiated components into coherent constructor structure
5. Establishes inter-component connections (static-dynamic, dynamic-learning, learning-static)
6. Validates generated constructor against essential properties
7. Issues certification or returns errors
8. Incorporates feedback about constructor performance into template refinement

## Essential Properties

Generated constructors must satisfy:

- **Generative Closure**: Can produce workflow generation systems that generate valid workflows
- **Three-Level Architecture**: Static, dynamic, learning design unified by feedback
- **Context Adaptability**: Configurable for diverse kitchen contexts
- **Feedback Integration**: Loops connect execution outcomes to generative modification
- **Traceability**: Practitioners can understand and verify outputs

## Relationship to Domain

The Constructor Generator produces what the L1P2 skill builds directly. It extends the generative hierarchy by one level:

```
Constructor Generator (L2P2)
    ↓ produces
Constructor (L1P2 artifact)
    ↓ produces
Workflow Generation System (L0P2 output)
    ↓ produces
Workflow Instance (L0P3 artifact)
```

## Maintenance

The generator is not built once but maintained continuously. Meta-level feedback loops operate across extended timescales:

- Constructor Performance Feedback: Patterns across multiple generated constructors
- Domain Evolution Feedback: Kitchen domain changes require specification updates
- Architecture Improvement Feedback: Generator architecture refines based on evidence

The generator's identity resides in its template library and its participation in the meta-learning cycle.

## Output

A deployable Constructor Generator instance comprising:

- Template Library (grammar, pattern, architecture, feedback templates)
- Generation Engine (specification processor, instantiation coordinator, assembly orchestrator)
- Validation Engine (structural, integration, generative, output validators)
- Feedback Integration System (metrics collection, pattern analysis, hypothesis generation, template modification)
- Documentation Bundle (grammar docs, architecture docs, configuration guides, maintenance guides)
