- Rhythm

## 2c. Fuse into One Glyph-Pattern

**Glyph:** ◌

**Readings:**

- **The empty circle** — what passes through it becomes what it needs to be. Input is irrelevant; only transformation matters.

- **The eye** — watching, then releasing. Attention given, attention returned.

- **The zero** — nothing, and therefore everything. No memory, no state, no weight.

- **The loop** — entry and exit are the same point. Where you begin is where you end.

**The compression:**

```
Intention → ◌ → Action
```

The glyph absorbs: rhythm, flow, threshold, the thing-that-becomes-other. It holds no content itself. It is pure passage.

---

## 2d. Retain Ambiguity Sufficient for Multiple Readings

The glyph ◌ refuses to be pinned to:

- A specific input type (text, number, gesture, voice)
- A specific output type (note, calculation, reminder, copy)
- A specific size (could be a browser button, a CLI command, a physical object)
- A specific domain (writing, math, time, communication)

**What it insists upon:**

- Something goes in
- Something comes out
- The thing in between is what the tool is
- The user should never notice the tool, only the result
