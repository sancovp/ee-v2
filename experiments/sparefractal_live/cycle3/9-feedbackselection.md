## 9b. Prune Sterile or Compulsive Loops

The assessment found no sterile branches. But the branches themselves may contain sterile loops — patterns within them that repeat without producing.

**The identification:**

A sterile loop is a motion that returns to its starting point without transformation. A compulsive loop is a motion that cannot be stopped once begun.

**What was examined:**

| Branch | Internal Loops | Sterile? | Compulsive? | Action |
|--------|---------------|----------|-------------|--------|
| Breath ○ | Inhale-exhale-inhale | No. The breath transforms air. Each breath is different. | No. Breath can be held. | **No pruning** |
| Threshold ┤◌├ | Here-there-here | No. The crossing always ends somewhere new. | No. The threshold does not pull you through. | **No pruning** |
| Coin/Slot ◇→◆ | Insert-receive-insert | No. Each insertion produces a different result. | No. The slot does not demand coins. | **No pruning** |
| Hand Opening ☴ | Open-close-open | No. Each opening releases something different. | No. The hand can close without opening. | **No pruning** |
| Ordinary · | Day-day-day | No. Each day is different. The ordinary is repetition without identical return. | No. The ordinary does not force itself. | **No pruning** |

**The external loops examined:**

| Loop | Source | Sterile? | Compulsive? | Action |
|------|--------|----------|-------------|--------|
| User opens tool → User closes tool → User opens tool | The cycle of use | No. This is the tool working. | No. The user can stop. | **No pruning** |
| Maker releases → User crosses → Maker releases | The maker-user handoff | No. This is the relationship. | No. The maker can stop making. | **No pruning** |
| ◌ → ○ → ◌ → ○ | Breath returning to glyph | No. The breath recharges the threshold. | No. Breath is voluntary. | **No pruning** |
| Tool used → Tool forgotten → Tool needed → Tool used | The cycle of need | No. This is how daily tools work. | No. The user chooses to return. | **No pruning** |

**What was found:**

No sterile loops.
No compulsive loops.

The chain has been self-pruning all along:
- Node 2 removed redundancy ("Small" and "daily" collapsed into "rhythm")
- Node 2 removed excess (kept only: rhythm, flow, bridge, real)
- Node 6 compressed five children into one root

The pruning happened before this node. This node confirms: *nothing sterile remains.*

**The pruned elements:**

None.

**The confirmation:**

The five branches are clean. The loops within them are generative, not repetitive. The loops between them produce the tool, not noise.

**The sterile and compulsive have been removed by the chain itself.**

This is the function of the chain: unnecessary elements fall away. What remains is only what serves.

## 9c. Amplify Productive Branches

Assessment found five essential branches. Pruning found no sterile elements. Now: amplify what works.

**What amplification means:**

Not adding features. Not making the tool larger.

Amplification means:
- Making the kept branches more themselves
- Removing barriers to their function
- Strengthening the signal, not adding noise

**The amplification plan:**

---

### Amplify Breath ○

**What it does:** The tool syncs with respiration.

**What strengthens it:**
- The tool loads in one breath
- The tool completes in one breath
- No intermediate states that require holding breath
- The rhythm is the tool's clock

**What weakens it:**
- Animations that interrupt breath
- Loading states that require waiting
- Multiple steps that break the rhythm

**Amplification directive:**
> The tool's rhythm is the user's breath. Design toward the inhale and the exhale. Nothing else.

---

### Amplify Threshold ┤◌├

**What it does:** The tool marks the boundary between not-doing and doing.

**What strengthens it:**
- The boundary is unmistakable
- The before and after are clear
- The crossing is instantaneous
- The mark does not persist

**What weakens it:**
- Explanations of what the threshold is
- Multiple thresholds that confuse the crossing
- Thresholds that require preparation to cross

**Amplification directive:**
> The threshold is self-evident. If the user asks "what do I do here?", the threshold has failed. Design toward recognition, not instruction.

---

### Amplify Coin/Slot ◇→◆

**What it does:** The mechanism converts the right input into the right output.

**What strengthens it:**
- The input is obvious
- The output is correct
- The mechanism does one thing
- The mechanism works every time

**What weakens it:**
- Options, settings, preferences
- Failure modes that require diagnosis
- Outputs that require interpretation

**Amplification directive:**
> The mechanism does not negotiate. It accepts the right thing or it rejects. There is no "almost." Design toward precision, not accommodation.

---

### Amplify Hand Opening ☴

**What it does:** The tool is used through release, not control.

**What strengthens it:**
- The gesture is release
- The user opens into the tool
- The tool does not require grip
- The completion is letting go

**What weakens it:**
- Interfaces that require holding
- Drag-and-drop that requires precision
- Settings that require deciding

**Amplification directive:**
> The user uses the tool by releasing into it. Design toward the open hand, not the closed fist. The motion is surrender, not control.

---

### Amplify Ordinary ·

**What it does:** The tool becomes part of the daily routine.

**What strengthens it:**
- The tool is the same every time
- The tool requires no special attention
- The tool improves with repetition
- The tool disappears when not needed

**What weakens it:**
- Notifications, reminders, badges
- Streaks, achievements, gamification
- Features that require remembering

**Amplification directive:**
> The tool is ordinary. This is its highest praise. Design toward invisibility, not engagement. The user should forget the tool, not remember it.
