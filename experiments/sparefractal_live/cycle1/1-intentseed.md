# NODE 1 · IntentSeed

## 1a. Concrete Desire

I want to build a tool so useful that it becomes invisible—a daily reflex, like checking the time.

## 1b. Stripped Core

*Something I reach for before thinking.*

## 1c. Emotional/Semantic Kernel

**Effortlessness → Reliability → Trust**

The desire is not to build something impressive. It is to build something that disappears into habit—where the user never has to think about the tool, only about their work.
